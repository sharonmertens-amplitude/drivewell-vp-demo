What to test, and in what order
Build one throwaway guide and point it at each section below. Each answers a question that changes how Michelle's builds have to be designed.
  • 1
    Repeating rows. Does a pin go to the first match? Does an element-click trigger fire on any row, or only the first? This decides the whole tag-icon build.
  • 2
    In-place modal. Can a pin anchor to something inside a dialog that renders where it sits in the DOM?
  • 3
    Body-portaled modal. Same question when the dialog is moved to the end of <body> on open — this is what Bootstrap does, and VIS is on Bootstrap.
  • 4
    Nested menu, removed from DOM. Mirrors the appraisal menu. Confirms the silent-failure behaviour.
  • 5
    Nested menu, present but display:none. Different case from #4 and may behave differently. Worth knowing which one VIS actually does.
  • 6
    Delayed element. How much trigger delay is needed when content arrives after page load.

3 · Modal moved to end of <body> on open
The markup does not exist until you click, and then it is appended to the end of the document rather than here. This is Bootstrap's behaviour, and VIS is on Bootstrap — so this is the case that most likely matches Michelle's Vehicle Tags window.
